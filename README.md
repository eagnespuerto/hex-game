A single-file HTML implementation of the connection game Hex. Red links top↔bottom, Blue links left↔right. CPU opponent uses Dijkstra-distance evaluation.

## Play

Open `index.html` in any modern browser, or deploy as a static site.

## Deploy on Render

1. New → Static Site → connect this repo.
2. Build command: *(leave blank)*
3. Publish directory: `.`

Render will serve `index.html` at the root.
